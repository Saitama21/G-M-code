# CNC Copilot — Коды и расчёты

Полностью автономная PWA для GitHub Pages. Объединяет справочник M- и G-кодов SINUMERIK 828D с модулем из 14 инженерных и цеховых расчётов.

## Что уже работает

- Справочник M- и G-кодов, поиск, категории, избранное и подробные карточки.
- Определитель резьбы, сверло под резьбу и профиль метрической резьбы.
- Геометрия конуса, шестигранника и поворота координат.
- Допуски ISO 286, шероховатость, истинная позиция и прогиб державки.
- Вес заготовки, болтовая окружность, измерение по трём проволочкам.
- Вершина сверла, время обработки и диагностика износа пластины.
- Сохранение результатов расчётов в локальную основу будущего раздела «Проекты».
- Единый нижний Dock и работа без сети после первого запуска.

## Как опубликовать через GitHub Pages

1. Создай новый репозиторий на GitHub, например `CNC-Copilot-Codes-Calculations`.
2. Загрузи **все файлы из этой папки в корень репозитория** и сделай Commit/Push.
3. Открой репозиторий → **Settings** → **Pages**.
4. В разделе **Build and deployment** выбери:
   - **Source:** Deploy from a branch
   - **Branch:** main
   - **Folder:** / (root)
5. Нажми **Save**. Через несколько минут появится адрес вида:
   `https://saitama21.github.io/CNC-Copilot-Codes-Calculations/`

## Установка на iPhone

1. Открой опубликованную ссылку в Safari.
2. Нажми «Поделиться».
3. Выбери «На экран Домой».
4. Один раз запусти приложение при наличии интернета — дальше справочник работает офлайн.

## Важно

- Сборка не требует Railway, сервера, npm или платного хостинга.
- Все пути относительные, поэтому приложение работает в подпапке GitHub Pages.
- Избранное хранится локально на устройстве.
- Нарисованного статус-бара внутри приложения нет — используется только системная панель iPhone.
