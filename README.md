# CNC Copilot — Справочник кодов

Полностью автономная PWA для GitHub Pages. Содержит M- и G-коды SINUMERIK 828D, поиск, категории, избранное, подробные карточки и цветные значки.

## Как опубликовать через GitHub Pages

1. Создай новый репозиторий на GitHub, например `CNC-Copilot-Codes-OFFLINE`.
2. Загрузи **все файлы из этой папки в корень репозитория** и сделай Commit/Push.
3. Открой репозиторий → **Settings** → **Pages**.
4. В разделе **Build and deployment** выбери:
   - **Source:** Deploy from a branch
   - **Branch:** main
   - **Folder:** / (root)
5. Нажми **Save**. Через несколько минут появится адрес вида:
   `https://saitama21.github.io/CNC-Copilot-Codes-OFFLINE/`

## Установка на iPhone

1. Открой опубликованную ссылку в Safari.
2. Нажми «Поделиться».
3. Выбери «На экран Домой».
4. Один раз запусти приложение при наличии интернета — дальше справочник работает офлайн.

## Важно

- Сборка не требует Railway, сервера, npm или платного хостинга.
- Все пути относительные, поэтому приложение работает в подпапке GitHub Pages.
- Избранное хранится локально на устройстве.
- Нарисованного статус-бара внутри приложения нет — используется только системная панель iPhone.
